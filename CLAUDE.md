# Gymthetic

Personal gym-knowledge site: exercise library, strength calculators, and a
localStorage-based progress tracker. Vite + React + TypeScript + Tailwind v4 +
React Router. No backend. Deployed to Vercel at gymthetic.vercel.app.

## Before starting work

Read `.claude/brain/feature/000-index.md` first — it's the living feature
inventory (one file per route/feature, numbered). `src/App.tsx` is the actual
source of truth for routes; regenerate the brain from it if they ever
disagree (the index file explains how).

## Workflow

See `.claude/rules/branching.md` for branching (there isn't one — direct to
master) and the required post-push deploy step.
